# Come Sit With Me

This folder is ready to upload as a static website.

## Files

- `index.html`: main site file for the web root

## Deploy

Upload the contents of this folder to your host's public web directory:

- cPanel/Shared hosting: usually `public_html/` or a subfolder for the domain
- Netlify: drag and drop this folder into the deploy UI
- GitHub Pages: place `index.html` in the publishing branch/folder

## Notes

- The page is self-contained and does not require a build step.
- It loads Google Fonts from `fonts.googleapis.com` and `fonts.gstatic.com`, so the host must allow outbound font requests in the browser.
- External site links have been switched to HTTPS for deployment.
- If you want social sharing previews, a real domain and preview image should be added later via full Open Graph tags.
